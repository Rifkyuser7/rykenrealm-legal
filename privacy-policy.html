Privacy Policy — RykenRealm

Terakhir diperbarui: 23 November 2026

Kebijakan Privasi ini menjelaskan data apa saja yang dikumpulkan, disimpan, dan diproses oleh bot Discord RykenRealm (selanjutnya disebut "RykenRealm" atau "Bot"), yang dikembangkan dan dikelola oleh Rizuki (@ryin.r). Dengan menggunakan Bot, kamu mengetahui dan menyetujui praktik yang dijelaskan di bawah ini.

Server komunitas resmi: https://discord.gg/kME469thr6

1. Data yang Dikumpulkan dan Disimpan

Bot dapat mengumpulkan dan menyimpan informasi berikut untuk menjalankan fitur serta mempertahankan progres pengguna:

  • Informasi Akun Discord — Discord User ID dan nama tampilan (display name) yang digunakan untuk mengenali pengguna serta menghubungkan data dengan akun mereka.
  • Informasi Server — Discord Guild ID yang digunakan untuk aktivasi server, pengelolaan whitelist, dan fitur khusus server seperti leaderboard.
  • Data Ekonomi Virtual — Saldo mata uang virtual, progres pekerjaan, kepemilikan properti virtual, catatan saham dan kripto virtual, serta progres lain yang berkaitan dengan sistem ekonomi Bot.
  • Data RPG — Level karakter, inventaris, progres dungeon dan tower, informasi crafting, serta data lain yang berkaitan dengan RPG.
  • Data Pasangan dan Keluarga Fiksi — Pilihan karakter anime, informasi hubungan fiksi, dan data anak fiksi yang berkaitan dengan fitur pasangan dan keluarga Bot.
  • Preferensi Pengguna — Pengaturan bahasa dan preferensi lain yang diberikan atau dipilih ketika menggunakan fitur Bot yang didukung.
  • Informasi Penggunaan dan Cooldown — Catatan penggunaan fitur, waktu cooldown, dan statistik aktivitas terkait yang digunakan untuk menjaga fungsi Bot serta membantu mencegah penyalahgunaan.

Bot tidak bermaksud menyimpan isi percakapan biasa yang bukan merupakan command sebagai bagian dari database pengguna. Namun, fitur tertentu dapat memproses aktivitas pesan sementara apabila diperlukan untuk menjalankan fungsinya, seperti sistem aktivitas chat atau pengalaman (XP).

2. Data yang Diproses oleh Layanan Pihak Ketiga

  • AI Chat dan Analisis Gambar — Pesan, prompt, atau gambar yang dikirim melalui fitur AI yang didukung dapat diteruskan ke Google Gemini API untuk diproses dan menghasilkan respons. Pengelolaan data oleh Google tunduk pada Kebijakan Privasi Google . Bot tidak bermaksud menyimpan histori percakapan AI secara permanen di database penggunanya.
  • Konversi Media — File yang dikirim melalui fitur konversi media berbasis lampiran dapat diproses sementara untuk menghasilkan file keluaran yang diminta. Prosesnya bergantung pada fitur dan jenis file yang digunakan. File yang diunggah tidak dimaksudkan untuk disimpan secara permanen oleh Bot setelah proses selesai.
  • Pencarian Karakter Anime — Nama karakter yang dikirim melalui fitur pasangan dapat diteruskan ke Jikan API untuk mengambil informasi karakter anime yang tersedia secara publik dari MyAnimeList.

3. Bagaimana Data Digunakan

Informasi yang dikumpulkan oleh Bot digunakan untuk tujuan seperti:

  • Menjalankan fitur Bot dan mempertahankan progres pengguna antar sesi.
  • Menampilkan leaderboard, peringkat, dan statistik di dalam server Discord yang mendukung fitur tersebut.
  • Mengelola preferensi pengguna dan pengaturan fitur.
  • Menerapkan cooldown serta membantu mencegah penyalahgunaan, eksploitasi, atau manipulasi sistem Bot.

Data pengguna tidak dijual atau disewakan kepada pihak ketiga. Bot tidak secara sengaja membagikan data pengguna kepada pihak ketiga untuk tujuan periklanan komersial.

4. Penyimpanan dan Keamanan Data

  • Data pengguna disimpan menggunakan database dan infrastruktur hosting yang dikonfigurasi untuk operasional Bot.
  • Akses ke lingkungan hosting dan database Bot dibatasi untuk pihak yang memiliki otorisasi pengelolaan.
  • Langkah-langkah yang wajar dilakukan untuk melindungi informasi yang disimpan. Namun, tidak ada layanan online atau sistem penyimpanan yang dapat menjamin keamanan secara mutlak.
  • Bot tidak meminta kata sandi Discord, detail kartu pembayaran, atau dokumen identitas resmi sebagai bagian dari fitur normalnya.

5. Layanan Pihak Ketiga

Bot dapat berinteraksi dengan layanan pihak ketiga berikut untuk menyediakan fitur-fiturnya:

Layanan Fungsi
Discord API Integrasi platform Discord dan fungsi Bot.
Google Gemini API Fitur AI chat dan analisis gambar.
Jikan API (MyAnimeList) Mengambil informasi karakter anime yang tersedia untuk publik.

Setiap layanan pihak ketiga beroperasi berdasarkan ketentuan dan kebijakan privasinya masing-masing. Praktik pengelolaan data mereka berada di luar kendali langsung pemilik Bot.

6. Hak Pengguna dan Penghapusan Data

Pengguna dapat:

  • Meminta Penghapusan Data — Hubungi Rizuki (@ryin.r) melalui server komunitas resmi untuk meminta penghapusan data yang terkait dengan akun Bot mereka. Permintaan dapat memerlukan verifikasi untuk memastikan bahwa data tersebut benar-benar milik pengguna yang mengajukan.
  • Berhenti Menggunakan Bot — Pengguna dapat berhenti berinteraksi dengan Bot kapan saja atau meminta administrator server Discord mengeluarkan Bot dari server.

Mengeluarkan Bot dari server atau berhenti menggunakannya tidak selalu menghapus data pengguna yang sebelumnya telah disimpan. Permintaan penghapusan data secara terpisah mungkin diperlukan.

7. Privasi Anak

Bot tunduk pada persyaratan usia minimum yang ditetapkan oleh Ketentuan Layanan Discord serta ketentuan lokal yang berlaku. Bot tidak ditujukan untuk digunakan oleh individu yang berada di bawah batas usia minimum yang diizinkan.

8. Perubahan Kebijakan

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu apabila diperlukan, termasuk ketika fitur Bot, praktik pengelolaan data, atau infrastruktur layanan mengalami perubahan. Versi terbaru akan dipublikasikan di Legal Center resmi. Perubahan penting juga dapat diumumkan melalui server komunitas resmi.
