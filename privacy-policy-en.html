Privacy Policy — RykenRealm

Last updated: October 22, 2026

This privacy policy explains what data is collected, stored, and processed by the Discord bot RykenRealm (hereinafter referred to as "RykenRealm" or the "Bot"), developed and managed by Rizuki (@ryin.r). By using the Bot, you agree to the practices described below.

Official community server: https://discord.gg/kME469thr6

1. Data Collected & Stored

The Bot stores the following data to ensure its features function properly:

  • Basic Discord Identity — Your Discord User ID and display name, so the Bot can recognize and address you correctly.
  • Server ID (Guild ID) — Used for server whitelist/activation systems and per-server leaderboards.
  • Virtual Economy Data — Virtual currency balances (clean cash, dirty cash), job history, virtual real estate ownership, virtual stocks/crypto, and other progress in the Bot's economy system.
  • RPG Data — Level, inventory, dungeon/tower progress, crafting status, and other RPG character data.
  • Fictional Partner/Family Data — The name of the anime character "married" (fetched from the public MyAnimeList database via Jikan API), relationship status, and fictional child data within that feature.
  • User Preferences — Language settings (/language), time zone for reminder/birthday features if provided.
  • Lightweight Usage Statistics — Chat level XP, feature cooldowns (e.g., when you last used /daily//hunt//heist) to prevent command abuse.

The Bot does not store regular message content (non-command chat) on servers. The Bot only processes messages starting with a command (/) to execute its features.

2. Data Processed but Not Stored Permanently

  • AI Chat Feature — Messages you send to the AI chat feature are forwarded to a third-party AI model provider (Google Gemini API) to be processed and answered. Data handling on that provider's side is subject to the Google Privacy Policy. The Bot itself does not permanently store AI conversation history in its database.
  • Media Downloader/Conversion Feature — Links or files you send to download/convert (e.g., video to MP3/Voice) are processed temporarily to generate the output file and are not stored after being sent back to you.
  • Anime Character Search — Character names you search for the partner feature are sent to the Jikan API (public MyAnimeList wrapper) to retrieve character data.

3. How Data Is Used

Stored data is used solely to:

  • Run and maintain the progress of Bot features (economy, RPG, partner system, etc.) across sessions.
  • Display leaderboards and statistics within the servers where the Bot is active.
  • Prevent system abuse (cooldowns, simple multi-account detection).

Data is not sold, rented, or shared with third parties for commercial or advertising purposes.

4. Data Storage & Security

  • Data is stored in database files on the Bot's hosting service (Railway) with persistent storage volumes.
  • Access to the hosting server and database is restricted exclusively to the Bot owner (Rizuki).
  • While security is prioritized, no system is 100% risk-free. The Bot does not store sensitive data such as passwords, payment info, or identity documents — the Bot never asks for such data.

6. User Rights

You have the right to:

  • Request Data Deletion — Contact Rizuki (@ryin.r) via the community server to request the deletion of your economy/RPG/partner data from the database.
  • Stop Using the Bot at Any Time — Simply by no longer using Bot commands or having a server admin remove the Bot from the server.

7. Children's Privacy

The Bot is not intended for children under the minimum age requirement specified by the Discord Terms of Service. The Bot does not knowingly collect data from users known to be under that age limit.

8. Policy Changes

This policy may be updated from time to time following updates to the Bot's features. The latest version will always be available in the same place, and major changes will be announced in the official community server.
