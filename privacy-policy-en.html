Privacy Policy — RykenRealm

Last updated: September 13, 2026

Bahasa Indonesia · English

This Privacy Policy explains what data is collected, stored, and processed by the Discord bot RykenRealm (hereinafter referred to as "RykenRealm" or the "Bot"), developed and operated by Rizuki (@ryin.r). By using the Bot, you agree to the practices described below.

Official community server: discord.gg/kME469thr6

1. Data We Collect & Store

The Bot stores the following data so its features can function:

  • Basic Discord identity — your Discord User ID and display name, so the Bot can recognize and address you correctly.
  • Server (Guild) ID — used for the server whitelist/activation system and per-server leaderboards.
  • Virtual economy data — virtual currency balances (clean cash, dirty cash), job history, virtual house ownership, virtual stocks/crypto, and other progress within the economy system.
  • RPG data — level, inventory, dungeon/tower progress, crafting status, and other RPG character data.
  • Fictional partner/family data — the anime character "married" (sourced from the public MyAnimeList database via the Jikan API), relationship status, and fictional children data within that feature.
  • User preferences — language setting (.language), timezone if provided for reminder/birthday features.
  • Lightweight usage stats — chat XP level, feature cooldown timestamps (e.g. last use of .daily/.hunt/.heist), used to prevent command abuse.

The Bot does not store the content of ordinary (non-command) chat messages in a server. It only processes messages that start with a command prefix (.) to run its features.

2. Data Processed but Not Permanently Stored

  • AI Chat feature — messages you send to the AI chat feature are forwarded to a third-party AI model provider (Google Gemini API) for processing and response generation. Handling of data on the provider's side is governed by Google's Privacy Policy. The Bot itself does not permanently store AI chat history in its own database.
  • Downloader/media conversion feature — links or files you submit for downloading/conversion (e.g. from Mediafire, video-to-MP3) are processed temporarily to generate the output file, then discarded after being sent back to you.
  • Anime character search — character names you search for the partner feature are sent to the Jikan API (a public MyAnimeList wrapper) to retrieve character data.

3. How Data Is Used

Stored data is used solely to:

  • Run and maintain your progress across the Bot's features (economy, RPG, partner system, etc.) between sessions.
  • Display leaderboards and statistics within the server where the Bot is active.
  • Prevent system abuse (cooldowns, basic multi-account detection).

Data is never sold, rented, or shared with third parties for commercial or advertising purposes.

4. Data Storage & Security

  • Data is stored as a database file on the Bot's hosting provider (Railway) using persistent storage volumes.
  • Access to the hosting server and database is restricted to the Bot owner (Rizuki) only.
  • While reasonable security measures are taken, no system is 100% risk-free. The Bot does not store sensitive data such as passwords, payment information, or any identity documents — the Bot never requests such data in the first place.

6. Your Rights

You have the right to:

  • Request data deletion — contact Rizuki (@ryin.r) via the community server to request that your economy/RPG/partner data be deleted from the database.
  • Self-service reset — some economy data can be reset by yourself using available Bot commands (e.g. .resetekonomi, with exceptions for partner/children data where applicable).
  • Stop using the Bot at any time — simply stop using Bot commands, or ask a server admin to remove the Bot from the server.

7. Children's Privacy

The Bot is not intended for children below the minimum age required under Discord's Terms of Service. The Bot does not knowingly collect data from users known to be below that age threshold.

8. Changes to This Policy

This Policy may be updated from time to time as the Bot's features evolve. The latest version will always be available at the same location, and material changes will be announced via the official community server.
